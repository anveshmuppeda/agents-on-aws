## 🤖 What is This?

This repo is a **complete, hands-on guide** to building AI agents on AWS using [Amazon Bedrock AgentCore](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/what-is-bedrock-agentcore.html).

Each guide teaches a specific concept with real source code, CDK infrastructure, shell scripts, architecture diagrams (Mermaid), and a cost estimate. Deploy one or all.

| AgentCore Service | What it does |
|---|---|
| 🚀 **Runtime** | Serverless microVM hosting — session isolation, any framework, any model |
| 🧠 **Memory** | STM + LTM — preferences, summaries, semantic facts, cross-agent sharing |
| 🔌 **Gateway** | MCP tool server — Lambda, OpenAPI, Smithy, semantic discovery, OAuth |
| 🔐 **Identity** | Workload identity, inbound JWT, outbound OAuth, consent flows |
| 📊 **Observability** | OTEL tracing, CloudWatch dashboards, cross-account, zero config |
| 🌐 **Browser** | Cloud browser — Nova Act, live view, human-in-loop, session recording |
| 💻 **Code Interpreter** | Sandboxed Python/JS/TS execution, large S3 files |
| ⚙️ **Harness** | Config-only agents — no Docker, no CDK, running in 30 seconds |
| 📈 **Quality** | LLM-as-Judge evals, AI prompt optimization, A/B testing, Cedar policies |
| 🗂️ **Registry** | Centralized tool catalog — publish, discover, cross-account sharing |
| 💳 **Payments** | x402 microtransactions, budget limits *(optional)* |
| 🤝 **Multi-Agent** | Orchestrator patterns, A2A, CrewAI, Step Functions, full production capstone |

## ⚡ Quick Start

> **New here? Start with guides 001–007** — they are available now and cover everything from local agents to your first AgentCore Runtime deployment.

### Step 1 — One-time setup (~10 min)

```bash
# Install Node.js CLI tools
npm install -g @aws/agentcore aws-cdk

# Clone the repo
git clone https://github.com/anveshmuppeda/agents-on-aws.git
cd agents-on-aws

# Create the shared Python virtual environment and install all packages
bash setup-env.sh
```

```bash
# Configure AWS
aws configure                                                  # set region: us-east-1
aws sts get-caller-identity --query Account --output text    # get your account ID
cdk bootstrap aws://YOUR_ACCOUNT_ID/us-east-1               # one-time CDK setup
```

> **Bedrock model access** — open the [Amazon Bedrock console](https://console.aws.amazon.com/bedrock/home?region=us-east-1#/modelaccess), enable **Amazon Nova Pro**, click Save.

### Step 2 — Verify setup

```bash
source .venv/bin/activate
cd 00-foundations/001-prerequisites
python3 verify_setup.py
# All 12 checks passed! You're ready to go. ✅
```

> **JSII Node warning?** Cosmetic — not an error. Silence it: `export JSII_SILENCE_WARNING_UNTESTED_NODE_VERSION=1`

### Step 3 — Run your first agent locally (no cost)

```bash
source .venv/bin/activate
cd 00-foundations/003-local-agent-strands
python3 Source/app/agent.py
```

### Step 4 — Deploy to AgentCore Runtime

```bash
source .venv/bin/activate
cd 01-runtime/006-agent-on-agentcore-runtime
bash deploy.sh      # ~5 min — Docker → ECR → CfnRuntime
bash invoke.sh      # test your live agent
bash destroy.sh     # ⚠️ always run this to stop billing
```

## 📐 Every Guide Has

```
NNN-guide-name/
├── README.md            ← What · Why · 3 Mermaid diagrams · Steps · Cost · Cleanup
├── deploy.sh            ← CDK deploy (auto-activates .venv, sets AWS_PROFILE)
├── invoke.sh            ← Test the deployed agent via boto3
├── invoke-dev.sh        ← Test against local dev server
├── dev.sh               ← Local hot-reload dev server
├── destroy.sh           ← Teardown — removes ALL AWS resources
├── Source/
│   ├── app/agent.py     ← Agent code (BedrockAgentCoreApp + @app.entrypoint)
│   ├── requirements.txt
│   └── Dockerfile       ← ARM64, port 8080
└── Infra/
    ├── app.py           ← CDK entry point
    ├── cdk.json
```
